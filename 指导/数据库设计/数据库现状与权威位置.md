## 表与模型

当前 init.sql 中有 34 个 `CREATE TABLE IF NOT EXISTS` 声明，共享 models.py 声明 18 个 ORM 表映射。初始化表多于该单一共享模型文件的映射数，不代表其余表未被其他编排模块使用。

| 领域 | DDL 中的表 |
| --- | --- |
| 身份与对话 | `users`、`user_api_keys`、`chat_sessions`、`messages` |
| 学习与教师内容 | `mistake_records`、`flashcards`、`study_plans`、`knowledge_documents`、`kb_chunks`、`memories`、`lesson_plans`、`presentations`、`exam_papers`、`learning_analyses` |
| 编排与审计 | `agent_runs`、`tool_call_audits`、`sub_agent_definitions`、`skill_definitions`、`context_compactions`、`guardrail_decisions`、`plan_documents`、`stop_hook_audits` |
| 成本与推荐 | `denial_counters`、`cost_ledger`、`model_prices`、`suggestion_logs` |
| 增强机制 | `dream_runs`、`feature_gates`、`output_styles`、`automation_hooks` |
| 订阅与支付 | `plans`、`subscriptions`、`orders`、`quota_periods` |

`study_plans` 是学习计划，`plans` 是订阅套餐；两者不可混同。知识库分块与记忆使用 pgvector，初始化包含 vector/pgcrypto 扩展以及余弦距离 ivfflat 索引；索引参数与数据量说明以 SQL 原注释为准。

## 已有数据库兼容

独立兼容补丁列出 10 张表的 52 项补列定义，涉及 `mistake_records`、`flashcards`、`study_plans`、`knowledge_documents`、`kb_chunks`、`memories`、`lesson_plans`、`presentations`、`exam_papers`、`learning_analyses`。补丁保留旧列与既有数据，仅在新增列时进行原脚本定义的回填；重复执行不应覆盖已存在列的值。

`init.sql` 的首次初始化逻辑包含相同补丁。已有业务卷不能通过重跑整份初始化或删除卷来替代兼容操作。运行步骤和限制见[项目说明](../架构优化/项目说明.md#已有数据库卷的兼容修复)；本次整理没有执行这些步骤。

## 数据隔离与验证边界

DDL 定义 RLS 策略并使用 `app.current_user_id` 判定归属；部分归属通过父表关联。非超级用户应用角色方案位于 init.sql，存在策略不等于当前部署连接一定受到 RLS 约束。实际用户上下文、应用角色、后台任务及无上下文拒绝仍应按[现状与路线图](../架构优化/项目开发现状与路线图.md)所列范围验证。

数据库表结构、ORM 和接口规范发生冲突时，应检查实际部署与迁移情况，不根据本索引推断数据库已完成升级。凭证只按现有环境配置管理，不写入指导文档。
