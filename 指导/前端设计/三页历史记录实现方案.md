# 聊天、错题本、卡片历史记录实现方案

日期：2026-11-04。状态：本地 HTML demo 完成，未上线、未接入后端。

## 已完成的 demo

三页顶部均增加“历史记录”按钮，打开对应记录子页；底部保留来源 Tab 高亮。列表支持标题／知识点搜索、空态提示、清空搜索、返回来源页面。

- 聊天历史：复用“我的”里的学习问答记录，包含原样例和本次提问。可恢复问题与回答并继续提问；两处历史读取同一份本地数据。
- 错题历史：两条初始样例。查看讲解或进入变式练习时，记录知识点、学科与操作；同一知识点移到最近位置。点击历史恢复对应学科筛选，并定位错题。
- 卡片历史：保存初始卡组，以及每次成功准备的范围题卡。每组保存题目、答案、范围、已评价张数和评价；可恢复未完成进度，已完成卡组可从头重开。生成新卡组不会覆盖旧组快照。
- 隐私重置：恢复初始聊天、错题与卡片记录。新增状态仅存在当前页面内存，刷新即恢复样例；没有持久化用户学习数据或调用模型。

## 正式功能实现方案

聊天复用稳定会话ID及消息列表，继续提问追加到同一会话。错题记录以题目ID关联学习行为，定义重复访问合并与时间排序规则。卡片记录以卡组和题目ID保存进度、评价、范围及完成状态；恢复时按卡组版本校验，避免题目变化造成位置错配。

三个入口分别读取对应资源列表，支持分页、搜索、加载失败和失效记录提示；列表与详情共享状态。前端按来源路由保留查询、列表位置，恢复失败保留当前内容。后端对所有读写验证本人归属；时间采用服务端时间并在前端本地化。是否扩展现有数据表与接口，需后续核对项目契约后确定。本轮无接口或数据库改动。
