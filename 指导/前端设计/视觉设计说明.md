# 雅典娜之学 · HTML 视觉方案

状态：本地可交互设计原型，未接入模型或服务，未修改产品应用，未上线。

## 设计计划

- 受众与任务：沿用 EduAgent 的学生学习场景，以提问、理解解题思路、整理错题和记忆复习为主要任务。
- 视觉语气：书卷、理性、温润。保留前一版的纸面与赤陶，用古希腊题刻比例、橄榄枝和雅典娜石膏像表达求知主题；不复制其他产品的品牌图形。
- 令牌：纸张 `#F6F2EB`、卡片 `#FDFBF5`、墨褐 `#26201A`、次要文字 `#6E6459`、赤陶 `#C15F3C`、橄榄 `#69725A`。深色采用暖炭黑背景和暖白正文。
- 字体：中文大标题以系统宋体呈现书卷感，正文以系统中文无衬线保证可读；拉丁题签使用 Baskerville / Palatino。全部使用本机字体，无字体下载。
- 布局：桌面侧栏加舒展的阅读栏，顶部小型评审工具条；手机收敛为单栏与底部四项导航。装饰只在欢迎区集中出现，学习内容保持清楚。
- 签名元素：一幅雅典娜石膏像与橄榄枝的静态插画，配极细回纹；页面其余区域保持安静。
- 动效：只以短暂透明度与位移反馈状态，遵循减少动态效果设置；本轮不构建或接入 C++ 渲染模块。

## 交付与演示边界

最终入口为 [雅典娜美化方案.html](雅典娜美化方案.html)。HTML 使用原生 CSS / JavaScript，可本地双击打开；图像、样式和脚本均已内嵌；单独移动这一份 HTML 仍可预览，无需网络、安装依赖或启动服务。

支持桌面／手机预览、浅深主题、页面导航、错题学科筛选、记忆卡翻面与复习推进、示例学习计划及本地提问演示。所有题目、掌握度和个人信息都是示例；发送输入只显示本地演示回应，不会调用 AI 或上传内容。

以现有移动端功能作为视觉范围，未增加支付、提醒、排名或教师权限；运行配置和部署保持原状。业务源码及 SQL 只同步了因文档迁移而变化的注释引用，已验证可执行逻辑与 SQL 语句不变。

## 输入区留白与换行修订

输入文字独占上排，附件与发送按钮置于下排两端；统一 16px 顶部、12px 两侧及底部留白，按钮保持 44px。默认提示简化为“写下问题，一起想明白。”，320px 屏宽也能完整显示；长文本自动增高至六行，随后内部滚动，支持 Shift+Enter 手动换行。

## 验证

JavaScript 语法检查通过；独立 Chromium 通过 34 项检查，覆盖 320–1440px 布局、手机预览框、主题保留、筛选、翻卡、输入法与安全文本呈现、减少动态效果及键盘焦点。直接以 file 协议打开，零外部 HTTP 请求，零脚本及控制台错误。详见[验证记录](验证/README.md)。

这些结果仅验证离线设计原型，不代表正式业务联调或帧率性能验收。

输入区另通过 14 项布局与换行检查，见[专项验证](验证/输入区布局验证.json)。
