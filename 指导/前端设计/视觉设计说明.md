# 雅典娜之学 · HTML 视觉方案

状态：本地可交互设计原型，未接入模型或服务，未修改产品应用，未上线。

当前版本将手机交互优化与已有功能演示合并：保留推开式对话侧栏、边缘返回、卡片滑动评分、新对话撤销、可勾选学习计划，接入个人资料、会员外观、教辅书架、范围题卡和分模块历史。会话、收藏、最近学习与侧栏共用数据；每个卡组独立保存本次复习的题目快照和评分。当前验证以[原型集成回归](验证/README.md#原型功能集成2026-11-04)为准，下文各日期的验证记录保留为历史证据。

## 设计计划

- 受众与任务：沿用 EduAgent 的学生学习场景，以提问、理解解题思路、整理错题和记忆复习为主要任务。
- 视觉语气：书卷、理性、温润。保留前一版的纸面与赤陶，用古希腊题刻比例、橄榄枝和雅典娜石膏像表达求知主题；不复制其他产品的品牌图形。
- 令牌：纸张 `#F6F2EB`、卡片 `#FDFBF5`、墨褐 `#26201A`、次要文字 `#6E6459`、赤陶 `#C15F3C`、橄榄 `#69725A`。深色采用暖炭黑背景和暖白正文。
- 字体：中文大标题以系统宋体呈现书卷感，正文以系统中文无衬线保证可读；拉丁题签使用 Baskerville / Palatino。全部使用本机字体，无字体下载。
- 布局：仅保留手机演示，统一单栏与底部四项导航；宽屏居中展示最大 414px 的手机画布，手机按可用宽度显示。主题在“我的 → 设置”切换。装饰只在欢迎区集中出现，学习内容保持清楚。
- 签名元素：一幅雅典娜石膏像与橄榄枝的静态插画，配极细回纹；页面其余区域保持安静。
- 动效：侧栏、页面返回、更多工具与卡片翻转使用可中断的弹簧；卡片支持左右滑动评分。遵循系统与本地的减少动态效果设置，本地选择可跨刷新恢复。

## 交付与演示边界

最终入口为 [雅典娜美化方案.html](雅典娜美化方案.html)。HTML 使用原生 CSS / JavaScript，可本地双击打开，无需网络、安装依赖或启动服务。样式与脚本内嵌，首屏插画拆成同目录的 [400px WebP](hero-art-400.webp) 和 [800px WebP](hero-art-800.webp)；复制或发送预览时请一起保留这三个文件。

支持手机画布预览、浅深主题、页面导航、错题学科筛选、记忆卡翻面与复习推进、示例学习计划及本地提问演示。所有题目、掌握度和个人信息都是示例；发送输入只显示本地演示回应，不会调用 AI 或上传内容。会员按钮仅切换外观，教辅仅保存本次书架元数据，范围出题仅载入三类预置题卡。

本轮改动限于离线原型、插画资源、说明与验证材料；Flutter、后端、数据库与部署配置保持原状。

## 输入区留白与换行修订

输入文字独占上排，附件与发送按钮置于下排两端；统一 16px 顶部、12px 两侧及底部留白，按钮保持 44px。默认提示简化为“写下问题，一起想明白。”，320px 屏宽也能完整显示；长文本自动增高至六行，随后内部滚动，支持 Shift+Enter 手动换行。
