# 文档整理计划

整理文档、导航与文档引用，保持可执行逻辑、运行配置、SQL 语句和测试不变。12 处源码/SQL 文档注释引用由主代理更新，另存引用修正记录。

1. 清点项目中的说明、设计提示词、API 协议及安全报告，迁移前记录 SHA-256。
2. 按前端设计、后端设计、数据库设计、架构优化四类实际迁移文件；历史设计稿一并归档。
3. 更新被迁移文档之间的相对链接，保留正文及历史结论；根 README 保留统一入口。
4. 为数据库现状和运行时提示词建立权威位置索引，不移动运行所依赖的文件。
5. 核对迁移完整性、内容差异范围、文档本地链接及遗漏，保存迁移清单。

边界：依赖清单、包配置、运行时 YAML/代码提示词、密钥、许可证必要原位、构建与第三方依赖不作为人读设计文档迁移；不安装、不启动服务、不提交或发布。
